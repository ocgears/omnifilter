This form allows you to select an image file from your local computer with the file picker. The image is then shown in the preview section so you can confirm it is the one you want. Then pick a filter and adjust its settings, or stack several: each one is applied to the result of the ones above it, with a strength and a blend mode, like layers in a photo editor. A preset look fills in a stack you can then adjust. Clicking transform sends the image to the server, which runs the filters on its GPU, and the result appears below.
